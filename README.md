# Homegame Turnieruhr

Poker-Turnieruhr für Homegames: Chips, Blindstruktur, Timer mit Ansagen, Spieler und Tische, Rebuys, Auszahlung und Deal-Rechner.

Läuft als Web-App unter https://samgula.github.io/Poker-Turnieruhr/. Auf dem iPad in Safari öffnen, „Teilen“ → „Zum Home-Bildschirm“. Danach funktioniert sie auch ohne Internet. Ergebnisse und Vorlagen werden auf dem Gerät gespeichert.
